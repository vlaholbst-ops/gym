# Зал — программа «Верх / Низ / Всё тело»

Мобильная страница-компаньон: https://vlaholbst-ops.github.io/gym/

## Как устроено

Это мобильная страница для тренировки по трёхдневной программе. Выполненные подходы
сохраняются прямо из страницы в личный [журнал Google Таблиц](https://docs.google.com/spreadsheets/d/1BRNnPLaVh2a_9HHAKvLXgrDgGITnq5c5qW7u2fAqNzk/edit).

| Файл | Что в нём |
|---|---|
| `program.json` | Упражнения, техника, запреты, шаг прогрессии. **Весов здесь нет.** |
| `template.html` | Вёрстка страницы. Плейсхолдеры `{{DAYS}}`, `{{WARMUP}}`, `{{PHOTO*}}`. |
| `build.mjs` | Читает прежний локальный журнал → считает стартовые веса → собирает `index.html`. |
| `index.html` | **Генерируется. Руками не править.** |

## После тренировки

1. Отметь галочкой выполненные подходы и при необходимости добавь заметку.
2. Нажми **«Сохранить»**. При первом нажатии Google попросит войти и дать доступ.
3. Кнопка **«Журнал»** открывает таблицу с одной строкой на каждый выполненный подход.

Страница при открытии тихо синхронизирует журнал и пересчитывает «Прошлый раз» и следующий
вес. Если вход в Google нужен повторно, нажми **«↻ Веса»** в шапке.

После успешного сохранения тренировка помечается как «В журнале» — так случайный повторный
клик не создаст дубликаты. Если нужно исправить уже отправленный подход, правь его в таблице.

Для публикации изменений пересобери страницу командой `node build.mjs` и закоммить
обновлённый `index.html` вместе с исходниками.
